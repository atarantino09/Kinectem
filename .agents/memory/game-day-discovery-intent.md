---
name: Game-day discovery intent
description: Product intent for the home feed's Following and Explore modes
---

Keep Following as the default complete chronological timeline. Explore is a separate discovery mode with one story visible at a time; mobile users swipe and desktop users use arrows. It never advances automatically. Recommendations must match self-provided sport or location signals, with an honest empty state when there is no relevant content; do not replace that with random global posts or IP-derived location.

**Why:** The user explicitly chose a one-story-at-a-time, deliberate browsing experience and wanted the familiar Following timeline preserved.

**How to apply:** When extending the home feed, avoid changing Following's data semantics or introducing autoplay/global discovery without a new product decision.
