---
name: Compact competition recap layout
description: Keep competition recap browsing compact without losing bracket and date organization
---

Competition featured recaps should fill the available grid space rather than
start a new row for every bracket or week. Preserve the organizer's bracket
order and date ordering, with bracket identity on cards and available filters.

**Why:** The user reported excessive empty space when groups containing only
one or two recaps reserved an entire row.

**How to apply:** Retain logical grouping for ordering and filtering without
forcing visual group boundaries to leave unused columns.
